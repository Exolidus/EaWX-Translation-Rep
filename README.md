# 🌐 Группа Переводчиков EaWX (Localization Repository)

Добро пожаловать в официальный репозиторий группы перевода модов серии **EaWX** (*Thrawn's Revenge*, *Fall of the Republic* и др.). 

Это пространство предназначено для обмена актуальными файлами локализации, совместной правки текстов и хранения вспомогательных инструментов.

---

### 📌 Описание
Это репозиторий для обмена переводом и установки скриптов для перевода, он будет открыт для редактирования для корректировщиков.

### 🛠 Инструментарий
В папке `scripts` находятся Python-утилиты для автоматизации обработки XML и TXT файлов. 
*Перед использованием скриптов убедитесь, что у вас установлены необходимые зависимости.*

---

### ⚠️ Важные правила работы (Для корректировщиков)

Чтобы не нарушить работу игрового движка и сохранить совместимость с компилятором, строго соблюдайте следующие правила:

1. **Сохранение структуры:** Категорически запрещено изменять внутреннюю структуру файлов `.xml` и `.txt`.
2. **Кодировка:** Все файлы должны сохраняться в исходной кодировке (обычно UTF-8 или UTF-16 LE, в зависимости от конкретного файла мода).
3. **Кэш переводов:** Если вы используете наш скрипт с флагом базы данных, не удаляйте файл кэша локально, чтобы не дублировать работу.

### 🚀 Как внести вклад
1. Получите роль **Корректор** в нашем Discord-сервере.
2. Сделайте `git clone` репозитория.
3. После внесения правок создайте **Commit** с кратким описанием изменений (например: *"Исправлены опечатки в описании юнитов Империи"*).
4. Сделайте **Push** в соответствующую ветку проекта.
